# Contributing

This repo is a playbook, not a product. Useful changes are clearer prompts, safer MCP notes, and measurements you actually ran.

## Pull requests

- Keep the voice plain. No invented scores.
- Do not add `wp-config.php`, `.env`, SQL dumps, FTP details, or a full `public_html`.
- If you ran the prompts on another site, a short note in an issue is more useful than a screenshot of a 100.

## Issues

Say which prompt you pasted, what the tool returned, and which URL you were on. If the model changed something you told it not to, paste that instruction too.

Never put a password, application password, or database string in an issue.
